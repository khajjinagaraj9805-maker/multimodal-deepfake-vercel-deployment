
# MULTI MODAL DEEP FAKE DETECTION PROJECT

A multimodal deepfake detection system designed to analyze text, images, videos, and audio using AI-based detection models.

## Technologies
- Python
- Flask
- HTML, CSS, JavaScript, Bootstrap
- MySQL
- SQLAlchemy
- PyTorch and ONNX Runtime

## Modules
- Text deepfake detection
- Image deepfake detection
- Video analysis
- Audio deepfake detection

## Setup
1. Create and activate a Python virtual environment.
2. Install the dependencies from requirements.txt.
3. Configure database credentials using environment variables.
4. Add the required model files.
5. Run the Flask application locally.

## Note
Model files, database credentials, and private user uploads should not be committed to the repository.
